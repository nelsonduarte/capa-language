# short_uuid

A short-ID generator of the shortuuid / nanoid shape (`shortuuid`
has ~3M downloads/month on PyPI; `nanoid` is the other widely-
used variant).

## What the library does

Generates a random URL-safe identifier of a requested length by
drawing characters from a 57-character visually-unambiguous
alphabet (the shortuuid default, which excludes `0`, `1`, `O`,
`I`, and `l` so IDs survive being read off a screen and typed
into a form). The public API is `generate(length: int = 22) -> str`.

## Authority surface

`Random` exercised in one function; the validator and alphabet
helpers are pure.

## Why representative

Three reasons:

1. **It is widely deployed.** `shortuuid` is one of the most-
   downloaded Python identifier libraries (~3M downloads/month);
   `nanoid` ships the same pattern with a slightly different
   alphabet and similar popularity. Many Python services mint
   IDs in this style for URLs, database keys, and API tokens.
2. **The shape conflates Random with pure helpers under one
   signature.** Same structural failure as `dotenv`'s
   `load_dotenv(path)`: the single public function does the
   capability-bearing work AND the pure work (alphabet
   definition, length validation), but the signature names
   neither concern. A CVE-style swap that replaced
   `secrets.choice` with a `random.choice` seeded from the wall
   clock (silently downgrading security) would not change the
   signature and would barely change the PURL SBOM.
3. **It is the first `Random`-bearing pair in the corpus.** The
   existing pairs cover `Fs`, `Env`, `Net`, and pure-stdlib
   over-attribution; this one extends axis coverage to the
   CSPRNG authority that Capa tracks via the `Random` capability.

## Functions

| Function | Signature shape | Declared capabilities |
|---|---|---|
| `default_alphabet` | `() -> String` | *(none)* |
| `is_valid_length` | `(Int) -> Bool` | *(none)* |
| `generate` | `(Random, Int) -> String` | `Random` |
| `main` | `(Stdio, Random)` | `Stdio`, `Random` |

## Naive Python's PURL SBOM proxy

The top-level import block is `import secrets`. A PURL-based SBOM
generated by syft / pip-licenses for this file would list
`secrets` (a capability-bearing stdlib module). It would say
nothing about which functions exercise the CSPRNG and which are
pure helpers around it.

The Capa SBOM names `Random` on `generate` only and proves the
helpers (`default_alphabet`, `is_valid_length`) cannot touch it.
